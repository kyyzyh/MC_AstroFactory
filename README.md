# AstroFactory

在 Minecraft 里搭建自动化工厂流水线。玩法取自《异星工厂》的「采矿 → 运输 → 加工 → 入库」闭环，
视觉与交互贴近《幸福工厂》的第一人称沉浸感，但坚持**可见的物理物流**：不做管道、不做无线传输。

- Minecraft **1.21.1**
- NeoForge **21.1.248**（1.21.1 线）
- 需要 **Java 21**
- 当前版本 **0.7.0**（修复掉落丢内容物 / 科技不同步 / 箱子无法手动存取）

## 安装

1. 安装 Minecraft 1.21.1 + NeoForge 21.1.248（HMCL 等启动器可直接装）。
2. 把 `astrofactory-0.7.0.jar` 放进 `mods` 目录。
3. 启动游戏，创造模式物品栏里找「星际工厂」分类。

## 玩法：从徒手伐木到全自动工厂

### 贫瘠开局（v0.5 重构，借鉴异星工厂前期流程）

开局**只有研究台、研究包、扳手、木箱**可用，其余全部锁进科技树——
对应异星工厂「徒手伐木 → 手挖矿 → 第一个红瓶科技」的体验：

1. **徒手时代**：手挖铁矿/铜矿，用原版熔炉烧成铁板/铜板。
2. 合成**研究包**（铁板 + 铜板 → 2 个，红瓶精神），投入研究台攒科技点。
3. 研究**基础自动化**（10 点）→ 解锁传送带、机械臂、储物箱。
4. 逐步解锁采矿 → 冶炼 → 蒸汽 → 物流 → 电力 → 组装，走出自己的自动化工厂。

### 燃料时代

- **机器烧燃料运转**：手持煤 / 木板 / 原木等右键机器投入燃料。
  - 煤 = 1600 tick，煤块 = 16000 tick，木板 / 原木 = 300 tick。
  - 燃料模式下机器工作周期 **×2**（慢），但不需要电。
- **研究台**：右键投入研究包；每 60 tick 消化 1 个初级包 = **10 科技点**，高级包 = **20 科技点**。

### 蒸汽动力链（v0.5 新增，电力时代入口）

水与蒸汽不走流体方块，走内部缓冲 + 相邻直连（抽水机 → 锅炉 → 蒸汽机依次相邻），保持「可见物理」风格：

| 方块 | 作用 |
|------|------|
| 抽水机 | 邻水（四周或下方）产水，推给相邻锅炉 |
| 锅炉 | 烧燃料 + 水 → 蒸汽；手持可燃物右键投料 |
| 蒸汽机 | 1 蒸汽 = 20 FE，40 FE/t 发电，缓存 100 000 FE，只出不进 |

**v0.6 配比（对齐异星工厂）**：1 抽水机（2 水/t）→ 1 锅炉（2 蒸汽/t）→ **2 蒸汽机**（各 1 蒸汽/t）。
锅炉把蒸汽**均摊**给相邻的所有蒸汽机（从轮转起点开始分），因此两台蒸汽机产出相同，
不必再像异星工厂那样手工配平。

蒸汽机发的电通过**动力电缆**供给电动采矿机等机器，是燃料发电机之外的另一条电力路线。

### 物流扩展（v0.5 新增）

| 方块 | 作用 |
|------|------|
| 木箱 | 9 格，**无科技锁**，开局即可用 |
| 铁箱 | 54 格大容量（需「物流学」） |
| 分流器 | 交替把物品导向左前 / 右前，一分为二 |
| 地下传送带 | 入口 + 出口配对（最长 8 格，可穿越地形），出口前方优先入容器 |

### 矿石链与直连（v0.6 新增，对齐异星工厂前期）

| 机制 | 说明 |
|------|------|
| 矿石识别 | 采矿机下方是铁矿/铜矿/金矿/煤矿时，产出对应**原矿**（粗铁 / 粗铜 / 粗金 / 煤），由熔炉炼成锭 |
| 直连熔炉 | 产物是矿石且相邻是熔炉 → **直接投进熔炉输入槽**，省掉传送带和机械臂 |
| 互喂煤 | 产物是燃料（煤）且相邻机器燃料槽未满 → 优先补燃料。两台采矿机放在煤矿上即可**燃料自给**，只需点火种 |
| 钢材二次冶炼 | 研究「钢材」后，熔炉可把**铁锭 → 钢板**（对应异星工厂 steel processing） |
| 电路板产物链 | 铜锭 → 铜缆（×2）；铜缆 + 铁锭 → 电路板（×3） |

### 科技树（DAG，11 节点，含 1 个触发型）

```
基础自动化 (10)
├─→ 自动采矿 (20) ─→ 高效采矿 I-III (40/级, 采矿+20%/级)
│        └──────→ 自动冶炼 (30) ─→ 高效冶炼 (60, 熔炉+30%)
│                       ├──────→ 蒸汽动力 ⚡触发型（做出 16 铁锭）
│                       └──────→ 钢材 (40, 铁锭→钢板)
└─→ 物流学 (40, 分流器/地下带/铁箱, 传送带+50%)
              ┌──────────┘
        电力时代 (80, 前置: 蒸汽动力+物流学)
        ├─→ 高级研究 (100, 解锁高级研究包)
        └─→ 自动组装 (150, 高级包, 解锁组装机)
```

**⚡ 触发型科技**：借鉴异星工厂 2.0 的开局设计——最初几项科技不靠研究，
而是「做出指定物品」自动完成。蒸汽动力不做研究、不耗研究包，
做出 **16 个铁锭**即自动解锁（对应异星工厂「50 铁板触发 Steam Power」）。

| 科技 | 成本 | 前置 | 效果 |
|------|------|------|------|
| 基础自动化 | 10 | — | 解锁传送带、机械臂、储物箱（贫瘠开局第一科技） |
| 自动采矿 | 20 | 基础自动化 | 解锁自动采矿机 |
| 自动冶炼 | 30 | 自动采矿 | 解锁自动熔炉 |
| 蒸汽动力 ⚡ | 0（触发） | 自动冶炼 | 做出 16 铁锭自动解锁；解锁抽水机、锅炉、蒸汽机 |
| 物流学 | 40 | 基础自动化 | 解锁分流器、地下传送带、铁箱；传送带速度 +50% |
| 高效采矿 I-III | 40/级 | 自动采矿 | 每级采矿速度 +20%（等级科技） |
| 高效冶炼 | 60 | 自动冶炼 | 熔炉速度 +30% |
| 钢材 | 40 | 自动冶炼 | 熔炉可把铁锭二次冶炼成钢板 |
| 电力时代 | 80 | 蒸汽动力 + 物流学 | 发电机、电缆、扳手升级 |
| 高级研究 | 100 | 电力时代 | 解锁高级研究包配方 |
| 自动组装 | 150（高级包） | 电力时代 | 解锁组装机 |

### 科技树 GUI

- **研究台**空手右键 → 打开科技树界面
- **科技终端**（新物品）右键 → 随时随地打开科技树
- 界面功能：DAG 树状图（绿=已研究 / 蓝=可研究 / 黄=在研 / 灰=前置未满足）、
  悬停查看详情（成本、前置、描述）、**点击节点直接选定研究**
- 科技进度为世界级（所有玩家共享），通过服务端校验防作弊

### 电力时代

1. 蒸汽路线：抽水机 → 锅炉 → 蒸汽机（见上文蒸汽链）。
2. 燃料路线：合成**燃料发电机**（烧煤 40 FE/t，缓存 100 000 FE）和**动力电缆**（BFS 组网、公平分摊）。
3. **工程师扳手**右键机器 → 升级电力驱动（速度翻倍、不烧燃料）。
4. **高级研究包**（铁锭 + 传送带 + 研究包 → 2 个，绿瓶精神：用自动化产物造研究材料）驱动后期科技。

### 组装机（科技树终点）

- 3×3 网格 + 输出槽，自动匹配**任意工作台配方**
- 纯电力驱动：每次合成 300 FE，周期 40 tick
- 原料可由机械臂自动投放，成品自动推出到朝向容器

### 机器耗电（电力模式）

| 机器 | 每次工作耗电 | 工作周期 | 缓存 / 最大接收 |
|------|------|------|------|
| 自动采矿机 | 200 FE | 40 tick（燃料 80） | 20 000 / 200 FE |
| 自动熔炉 | 400 FE | 100 tick（燃料 200） | 20 000 / 200 FE |
| 机械臂 | 20 FE | 10 tick（燃料 20） | 20 000 / 200 FE |
| 组装机 | 300 FE | 40 tick（纯电力） | 20 000 / 200 FE |

## 方块与物品一览

| 名称 | 用途 |
|------|------|
| 传送带 | 单层水平输送，速度受「物流学」加成 |
| 机械臂 | 从后方容器抓取、投放到前方容器 |
| 自动采矿机 | 采下方方块，速度受「高效采矿」等级加成 |
| 自动熔炉 | 自动烧炼，速度受「高效冶炼」加成 |
| 储物箱 | 27 格通用容器 |
| 木箱 | 9 格，开局可用（无科技锁） |
| 铁箱 | 54 格大容量（需「物流学」） |
| 分流器 | 交替导向左前 / 右前，一分为二（需「物流学」） |
| 地下传送带 | 入口/出口配对穿越地形，最长 8 格（需「物流学」） |
| 抽水机 | 邻水产水推给锅炉（需「蒸汽动力」） |
| 锅炉 | 燃料 + 水 → 蒸汽（需「蒸汽动力」） |
| 蒸汽机 | 蒸汽 → FE 发电（需「蒸汽动力」） |
| 燃料发电机 | 烧燃料产电（40 FE/t） |
| 动力电缆 | 连接发电机与机器，组网分摊电量 |
| 研究台 | 投入研究包推进科技；空手右键打开科技树 GUI |
| 组装机 | 电力自动合成（需「自动组装」科技） |
| 工程师扳手 | 机器转向；电力时代后升级机器为电动 |
| 研究包 | 初级科技原料（铁板 + 铜板 → 2 个） |
| 高级研究包 | 后期科技原料（铁锭 + 传送带 + 研究包 → 2 个，需「高级研究」） |
| 科技终端 | 随身打开科技树 GUI |
| 钢板 | 钢材科技产物，高级研究包 / 科技终端 / 组装机的原料 |
| 铜缆 | 铜锭加工产物，电路板原料 |
| 电路板 | 铜缆 + 铁锭合成，高级研究包与科技终端原料 |

## 构建

```bash
# 需要 Java 21
./gradlew build
# 产物在 build/libs/astrofactory-0.7.0.jar
```

自检（无头服务器自动搭产线验证全流程）：

```bash
./gradlew runServer -Pselftest
# 日志中查找 [SELFTEST]，v0.7 为 39 项检查
```

## 项目结构

```
src/main/java/com/astrofactory/
├── block/        方块定义（传送带、蒸汽链、分流器、地下带等）
├── blockentity/  方块实体（PoweredBlockEntity 双模式基类、蒸汽链、箱子等）
├── item/         物品（扳手、科技终端、科技锁 BlockItem）
├── tech/         科技树（TechNodes DAG 定义、TechTreeData 等级进度）
├── menu/         菜单（科技树、组装机）
├── client/       GUI Screen（科技树 DAG 可视化、组装机）
├── network/      网络层（科技进度同步、选定研究请求）
├── registry/     注册（方块 / 物品 / 方块实体 / 菜单 / 创造页签 / 能力）
└── dev/          SelfTest 自检
tools/gen_textures.py   49 张 16px 贴图的程序化生成器
tools/gen_preview.py    贴图预览图生成器
```

## 版本历史

- **0.7.0** — 修复三项审查问题：① 拆机器时不再丢失内容物（`FactoryBlock.getDrops` 会从
  `LootParams` 取方块实体，把输入/输出/燃料/3x3 网格全部掉出来）；② 科技进度实时同步
  （研究台消化研究包、触发型科技解锁、自动选定研究目标后都会 `syncToAll`，GUI 不再显示旧状态）；
  ③ 储物箱/木箱/铁箱可用原版箱子 GUI 手动存取（实现 `Container` 接口，按容量自动选 1/3/6 行）。
  自检扩至 39 项（新增拆箱掉落与 Container 读写验证）。
- **0.6.0** — 触发型科技（做出 16 铁锭自动解锁蒸汽动力，不耗研究包，对应异星工厂 2.0 开局）；
  矿石链（矿石→原矿→熔炉炼锭）、采矿机直连熔炉、双采矿机互喂煤（燃料自给）；
  新增「钢材」科技与钢板二次冶炼（铁锭→钢板）、铜缆 + 电路板产物链；
  蒸汽链改为 1 抽水机 : 1 锅炉 : 2 蒸汽机均摊配比；科技树 11 节点、3 个新物品、49 张贴图、37 项自检。
- **0.5.0** — 贫瘠开局：开局仅研究台/研究包/扳手/木箱可用，其余锁进科技树；
  蒸汽动力链（抽水机 → 锅炉 → 蒸汽机，1 蒸汽 = 20 FE）；物流扩展（木箱 9 格 / 铁箱 54 格 /
  分流器交替导向 / 地下传送带穿地形 8 格）；科技树重构为 10 节点（新增蒸汽动力，
  基础自动化改为 10 点可研究）；研究包配方改为铁板 + 铜板（红瓶精神）、
  高级包改为铁锭 + 传送带 + 研究包（绿瓶精神）。7 个新方块、20 个配方、46 张贴图。
- **0.4.0** — 异星工厂式科技树重构：DAG 多前置、等级科技（高效采矿 I-III）、
  分级研究包（初级/高级）、科技树可视化 GUI（研究台 + 科技终端）、组装机（电力自动合成）、
  科技效果落地（传送带/采矿/熔炉速度加成）。
- **0.3.0** — 科技树：燃料时代（烧木头/煤，周期 ×2）→ 研究台 + 研究包 → 电力时代
  （扳手升级电动、发电机 + 电缆组网）；科技锁放置限制。
- **0.2.0** — 能源系统：发电机、电缆 BFS 组网、公平分摊；机器 FE 缓存与耗电。
- **0.1.0** — 核心闭环：传送带、机械臂、采矿机、自动熔炉、储物箱 + 能力互通。
