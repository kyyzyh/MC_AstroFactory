# AstroFactory

在 Minecraft 里搭建自动化工厂流水线。玩法取自《异星工厂》的「采矿 → 运输 → 加工 → 入库」闭环，
视觉与交互贴近《幸福工厂》的第一人称沉浸感，但坚持**可见的物理物流**：不做管道、不做无线传输。

- Minecraft **1.21.1**
- NeoForge **21.1.248**（1.21.1 线）
- 需要 **Java 21**
- 当前版本 **0.8.9**

## 安装

1. 安装 Minecraft 1.21.1 + NeoForge 21.1.248（HMCL 等启动器可直接装）。
2. 把 `astrofactory-0.8.9.jar` 放进 `mods` 目录。
3. 启动游戏，创造模式物品栏里找「星际工厂」分类（创造模式下全部内容已被完全解锁，方便体验全流程）。

## 玩法：从徒手伐木到全自动工厂

### 贫瘠开局

开局**只有研究台、研究包、扳手、木箱**可用，其余全部锁进科技树——
对应异星工厂「徒手伐木 → 手挖矿 → 第一个红瓶科技」的体验：

1. **徒手时代**：手挖铁矿/铜矿，用原版熔炉烧成铁板/铜板。
2. 合成**研究包**（铁板 + 铜板 → 2 个），投入研究台攒科技点。
3. 研究**基础自动化**（10 点）→ 解锁传送带、机械臂、储物箱。
4. 逐步解锁采矿 → 冶炼 → 蒸汽 → 物流 → 电力 → 组装，走出自己的自动化工厂。

### 燃料时代

- **机器烧燃料运转**：手持煤 / 木板 / 原木等右键机器投入燃料。
  - 煤 = 1600 tick，煤块 = 16000 tick，木板 / 原木 = 300 tick。
  - 燃料模式下机器工作周期 **×2**（慢），但不需要电。
- **研究台**：右键投入研究包；每 60 tick 消化 1 个初级包 = **10 科技点**，高级包 = **20 科技点**。

### 蒸汽动力链

水与蒸汽不走流体方块，走内部缓冲 + 相邻直连（抽水机 → 锅炉 → 蒸汽机依次相邻），保持「可见物理」风格：

| 方块 | 作用 |
|------|------|
| 抽水机 | 邻水（四周或下方）产水，推给相邻锅炉 |
| 锅炉 | 烧燃料 + 水 → 蒸汽；手持可燃物右键投料 |
| 蒸汽机 | 1 蒸汽 = 20 FE，40 FE/t 发电，缓存 100 000 FE，只出不进 |

**配比**：1 抽水机（2 水/t）→ 1 锅炉（2 蒸汽/t）→ **2 蒸汽机**（各 1 蒸汽/t）。
锅炉把蒸汽**均摊**给相邻的所有蒸汽机（从轮转起点开始分），因此两台蒸汽机产出相同，
不必再像异星工厂那样手工配平。

蒸汽机发的电通过**动力电缆**供给电动采矿机等机器，是燃料发电机之外的另一条电力路线。

### 物流扩展

| 方块 | 作用 |
|------|------|
| 木箱 | 9 格，**无科技锁**，开局即可用 |
| 铁箱 | 54 格大容量（需「物流学」） |
| 分流器 | 交替把物品导向左前 / 右前，一分为二 |
| 地下传送带 | 入口 + 出口配对（最长 8 格，可穿越地形），出口前方优先入容器 |

### 矿石链与直连

| 机制 | 说明 |
|------|------|
| 矿石识别 | 采矿机下方是铁矿/铜矿/金矿/煤矿时，产出对应**原矿**（粗铁 / 粗铜 / 粗金 / 煤），由熔炉炼成锭 |
| 直连熔炉 | 产物是矿石且相邻是熔炉 → **直接投进熔炉输入槽**，省掉传送带和机械臂 |
| 互喂煤 | 产物是燃料（煤）且相邻机器燃料槽未满 → 优先补燃料。两台采矿机放在煤矿上即可**燃料自给**，只需点火种 |
| 钢材二次冶炼 | 研究「钢材」后，熔炉可把**铁锭 → 钢板**（对应异星工厂 steel processing） |
| 电路板产物链 | 铜锭 → 铜缆（×2）；铜缆 + 铁锭 → 电路板（×3） |

### 科技树（DAG，11 节点，含 1 个触发型）

```
基础自动化 (10)
├─→ 自动采矿 (20) ─→ 高效采矿 I-III (40/级, 采矿+20%/级)
│        └──────→ 自动冶炼 (30) ─→ 高效冶炼 (60, 熔炉+30%)
│                       ├──────→ 蒸汽动力 ⚡触发型（做出 16 铁锭）
│                       └──────→ 钢材 (40, 铁锭→钢板)
└─→ 物流学 (40, 分流器/地下带/铁箱, 传送带+50%)
              ┌──────────┘
        电力时代 (80, 前置: 蒸汽动力+物流学)
        ├─→ 高级研究 (100, 解锁高级研究包)
        └─→ 自动组装 (150, 高级包, 解锁组装机)
```

**⚡ 触发型科技**：借鉴异星工厂 2.0 的开局设计——最初几项科技不靠研究，
而是「做出指定物品」自动完成。蒸汽动力不做研究、不耗研究包，
做出 **16 个铁锭**即自动解锁（对应异星工厂「50 铁板触发 Steam Power」）。

| 科技 | 成本 | 前置 | 效果 |
|------|------|------|------|
| 基础自动化 | 10 | — | 解锁传送带、机械臂、储物箱（贫瘠开局第一科技） |
| 自动采矿 | 20 | 基础自动化 | 解锁自动采矿机 |
| 自动冶炼 | 30 | 自动采矿 | 解锁自动熔炉 |
| 蒸汽动力 ⚡ | 0（触发） | 自动冶炼 | 做出 16 铁锭自动解锁；解锁抽水机、锅炉、蒸汽机 |
| 物流学 | 40 | 基础自动化 | 解锁分流器、地下传送带、铁箱；传送带速度 +50% |
| 高效采矿 I-III | 40/级 | 自动采矿 | 每级采矿速度 +20%（等级科技） |
| 高效冶炼 | 60 | 自动冶炼 | 熔炉速度 +30% |
| 钢材 | 40 | 自动冶炼 | 熔炉可把铁锭二次冶炼成钢板 |
| 电力时代 | 80 | 蒸汽动力 + 物流学 | 发电机、电缆、扳手升级 |
| 高级研究 | 100 | 电力时代 | 解锁高级研究包配方 |
| 自动组装 | 150（高级包） | 电力时代 | 解锁组装机 |

### 科技树 GUI

- **研究台**空手右键 → 打开科技树界面
- **科技终端**（新物品）右键 → 随时随地打开科技树
- 界面功能：DAG 树状图（绿=已研究 / 蓝=可研究 / 黄=在研 / 灰=前置未满足）、
  悬停查看详情（成本、前置、描述）、**点击节点直接选定研究**
- 科技进度为世界级（所有玩家共享），通过服务端校验防作弊

### 电力时代

1. **蒸汽路线**：抽水机 → 锅炉 → 蒸汽机（1:1:2 配比，1 蒸汽 = 20 FE）。
2. **燃料路线**：合成**燃料发电机**（烧煤 40 FE/t，缓存 100 000 FE）和**动力电缆**（BFS 组网、公平分摊）。
3. **电线杆覆盖式电网**：立电线杆，杆间距 ≤10 格自动连线组网，供电半径 7 格；
   覆盖范围内的电力设备自动得电；电网按「网络」聚合计算（每 tick 汇总发电与需求再分配），
   拆杆时网络正确分裂。
4. **电力采矿机 / 电力机械臂**：接入电网后以 2 倍速度运转（采矿机 20 FE/t、1 矿/秒；
   机械臂 10 FE/t、1.2 次/秒），断电暂停保留进度，恢复继续。
5. **工程师扳手**右键机器 → 升级电力驱动（速度翻倍、不烧燃料）。

### 组装机 1 型

- 从**已解锁配方列表**选定目标产物，之后机器自动合成
- **定量投料**：只看每种原料够不够数，不看摆位，机械臂可从任意面塞料
- 纯电力驱动：耗电 30 FE/t，三种初始配方——铁齿轮（2 铁板 → 1 齿轮，2 秒）、
  铜线材（1 铜板 → 2 线，1 秒）、红瓶（1 齿轮 + 1 铜板 → 1 红瓶，5 秒）
- 缺料停等不耗电、输出满暂停、换配方退回已投入原料

### 科技树数据框架与配方锁定

- 科技定义**全部数据驱动**（DataGen 生成 JSON）：id、名称、前置、消耗科技包种类与数量、解锁配方列表
- 新增一项科技只需丢一个 JSON，不必改代码
- 研究进度为**世界级共享数据**（存档带版本号，多人看到同一进度）
- 配方锁定：科技没研究完，其解锁配方就从服务端配方表裁剪掉，工作台与组装机一起被拦，
  并把裁剪后的表广播给客户端，避免「客户端显示能做、服务端不给做」的错位

### 实验室与红瓶

- **实验室**耗电 20 FE/t，机械臂送入红瓶后自动喝瓶推进研究
- 多台实验室**并联线性加速**（共享世界级研究进度，各自消费红瓶）
- **研究界面**（LabMenu/LabScreen）：科技列表（含前置/消耗/进度）、选择当前研究、**支持排队**
- 瓶尽/断电暂停保留进度；研究完成弹出提示并自动解锁配方
- 红瓶配方：1 齿轮 + 1 铜板 / 5 秒，由实验室消费它自动推进

**当前科技主线**：基础自动化 → 自动采矿 / 自动冶炼 → 蒸汽动力（触发型）→ 物流学 /
  钢材 → 电力时代 → 高级研究 / 自动组装 → 自动化研究（实验室 + 红瓶）。

### 机器动效

每台工作机器在工作时都有对应功能的**活动部件动画**（客户端本地驱动，零网络同步、不逐 tick 遍历）：

| 机器 | 动画 |
|------|------|
| 采矿机 | 钻头下钻（竖直往复） |
| 机械臂 | 摆臂抓取 |
| 蒸汽机 | 旋转飞轮 + 往复活塞 |
| 抽水机 | 活塞上下抽动 + 出水管脉动 |
| 发电机 | 旋转转子 + 燃烧辉光 |
| 组装机 | 双爪抓取往复 |
| 锅炉 / 熔炉 | 炉膛火焰跳动 |
| 实验室 | 研究光脉动 |

### 机器耗电（电力模式）

| 机器 | 耗电 | 工作周期 | 缓存 / 最大接收 |
|------|------|------|------|
| 自动采矿机（燃料） | 200 FE/次 | 40 tick | 20 000 / 200 FE |
| 自动熔炉 | 400 FE/次 | 100 tick（燃料 200） | 20 000 / 200 FE |
| 机械臂（燃料） | 20 FE/次 | 10 tick | 20 000 / 200 FE |
| 电力采矿机 | 20 FE/t | 20 tick（1 矿/秒） | 10 000 / 200 FE |
| 电力机械臂 | 10 FE/t | 17 tick（1.2 次/秒） | 10 000 / 200 FE |
| 组装机 | 30 FE/t | 随配方（缺料不耗电） | 20 000 / 500 FE |
| 实验室 | 20 FE/t | 60 tick/红瓶 | 10 000 / 200 FE |

电线杆覆盖式电网参数：供电半径 7 格、连线距离 ≤10 格、每电网最大传输 2000 FE/t。

## 构建

```bash
# 需要 Java 21
./gradlew build
# 产物在 build/libs/astrofactory-0.8.9.jar
```

自检（无头服务器自动搭产线验证全流程）：

```bash
./gradlew runServer -Pselftest
# 日志中查找 [SELFTEST]
```

GameTest（功能回归，37 项）：

```bash
./gradlew runGameTestServer
```

## 项目结构

```
src/main/java/com/astrofactory/
├── block/        方块定义（传送带、蒸汽链、分流器、地下带、电线杆、组装机、实验室等）
├── blockentity/  方块实体（FactoryBlockEntity / PoweredBlockEntity 双模式基类、蒸汽链、箱子等）
├── item/         物品（扳手、科技终端、科技锁 BlockItem）
├── tech/         科技树（TechNodes 硬编码节点 + TechRegistry 数据驱动 + TechTreeData 等级进度 + 配方锁定）
├── recipe/       自定义配方（AssemblerRecipe 组装机定量投料配方）
├── power/        电力（电网聚合、能量缓冲）
├── menu/         菜单（科技树、组装机、锅炉、蒸汽机、电线杆、实验室）
├── client/       GUI Screen（科技树 DAG 可视化、组装机、实验室、电线杆渲染、机器动效）
├── network/      网络层（科技进度同步、选定研究请求、排队请求）
├── registry/     注册（方块 / 物品 / 方块实体 / 菜单 / 配方 / 创造页签 / 能力）
├── datagen/      数据生成（组装机配方、科技 JSON、物品标签）
├── gametest/     GameTest（蒸汽链、电网、电力机器、组装机、实验室、科技锁定、状态迁移）
└── dev/          SelfTest 自检
tools/            Python 贴图生成器
```
